# Simple Portfolio Website

A simple personal portfolio website built with **React.js** and **Vite**.  
This project can be cloned and run locally on any device.

🔗 Live Demo:  
https://arifalfarizy.github.io/simple-porto/

---

## 🚀 Tech Stack
- React.js
- Vite
- JavaScript (ES6+)
- HTML5 & CSS3
- GitHub Pages

---

## 🛠️ How to Run This Project on Your Device

Follow the steps below to run this project locally on your own device.

---

### ✅ Prerequisites
Make sure you have the following installed:
- **Node.js** (v18+ recommended)
- **npm** (comes with Node.js)
- **Git**

Check installation:
```bash
node -v
npm -v
git --version
```
Clone the Repository
```bash
git clone https://github.com/ArifAlfarizy/simple-porto.git
```

Enter the Project Directory
```bash
cd simple-porto
```

Install Dependencies
```bash
npm install
```

Run the Project
```bash
npm run dev
```
The App will run locally at: http://localhost:5173
